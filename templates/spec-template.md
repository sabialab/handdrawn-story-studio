## 〇、故事来源（**先填这个。填不出来就别往下做**）

| 项 | 值 |
|---|---|
| **故事来源** | 〔`firsthand` 亲历 / `adapted` 转述改编 / `fiction` 虚构——三选一，不许含糊〕 |
| 素材出处 | 〔具体到哪一条记录 / 哪个公开可查事件 / 纯创作〕 |

**同质化自查**：

- 本片故事内核来自：〔具体素材源，不许与近 30 天雷同〕
- 「情景 + 冲突 + 结局」三元组与近 30 期比对结论：〔查重输出〕
- **画风一致 ≠ 情景雷同**：画风必须保持一致，情节结构必须真的不同。

## 一、定位与边界

- **单画幅**：只注册一个 Composition，〔1080×1920 / 30fps〕。
- 风格＝手绘故事风：速写本纸底 + 线条被画出来 + 局部蜡笔上色 + 顶部字幕带。
- **账号角标每片必带**：〔账号名，逐字来自 `editorial.md`〕，签名式、全片常驻、静态无动效。它是 theme 常量，**跨片不换**。
- 红线：画面零外链零 URL 零二维码；不出现他站账号名；禁彩色 emoji；**中文错字一票否决**；不碰需要资质的题材；不做恐吓焦虑式内容；不诱导转发。

## 二、转发动机与情绪终点（**必须填**）

| 项 | 值 |
|---|---|
| **忠告芯** | 〔那句能被带走的话，逐字〕 |
| **谁转给谁、为什么** | 〔答不上来就回提案段重想〕 |
| **命中的转发动机** | 〔实用价值 / 情绪态度 / 社交人设〕 |
| **情绪终点** | 〔停在哪种情绪上〕 |
| **有加害者时的自查** | 〔多数平台要求：加害者必须悔改、受惩罚，或叙述者明确表达批判态度，三者居其一〕 |
| **钩子自查** | 〔封面与前 3 秒**不得**拿冲突画面本身做钩子——钩子给处境，不给暴行〕 |

## 三、前置（顺序不能换）

1. 工程从母版复制：`cp -R $SKILL_DIR/video-template/handdrawn-master video-template/〔slug〕`（在项目根下敲；`$SKILL_DIR` ＝ 本包安装目录），按 `references/production.md` 第一节清场。`package.json` 只改 `name` 和渲染输出名，**依赖精确锁版不动**。
2. `npm install` 之后 `npx remotion versions` 必须报 "All packages have the correct version" 才继续。
3. `npx remotion browser ensure` 预装渲染浏览器（**建工程时就做**，否则会跟执行单里「禁止联网下载」撞车）。
4. 跑 `tools/fetch_fonts.sh`（幂等）。⚠️ `cp -R` 会把 `public/fonts` 软链展开成真目录，重跑即修复；**软链必须是目录级**。
5. 本机 Python 命令是 `python3`。

## 四、音频（合成后冻结，禁碰）

- 旁白稿 `script.json`（〔N〕段）已定稿并已过去AI味审校。
- 合成命令见 `references/narration.md` 第五节。
- `timeline.json` 即帧表 **T**，本片唯一时间锚点：**总长〔X.XX〕s ＝〔总帧〕帧 @〔fps〕**。
  **时长三写**：`durationInFrames = T.total_frames + 尾牌〔75〕帧 =〔合计〕帧 /〔fps〕=〔秒数〕s`（容器报告值会略长零点几秒，属正常）。
- **音频是构建产物，生成一次就冻结**：TTS 是抽卡的，同文本同参数每次时长都不一样。`public/voice/` 已存在就直接用，**不许重新生成**；所有帧号一律 T 表达式，**禁手写魔法帧数**。
- 字幕**行**停留不低于〔配置里的 `captions.minLineSeconds`，缺省 2.5s〕；短应答不低于〔1.2s〕。契约测试逐条卡这个。

| 文件 | 角色 | 备注 |
|---|---|---|
| `public/voice/narration.wav` | 旁白母带 | 一条铺到底，音量 1.0，**旁白是主角** |
| `public/audio/bgm.〔ext〕` | 唯一 BGM | 〔温暖钢琴 / 民谣吉他一类；不用 beat-drop〕基础音量〔0.10〕 |

|---|---|
| 前 3 秒钩子大字 | 130–170px |

| 字幕带 | 56px |

## 六、场景表（S1–S〔M〕 ↔ 帧表的 L1–L〔N〕）

坐标为〔1080×1920〕画布 px。zIndex：背景 0 / 配角 2 / 主角 5 / 标注 7 / 前景 9 / 字幕与大字 12。

| 场景 | 帧区间 | 画面 | 线稿与动画 | 音效（帧＝表达式） |
|---|---|---|---|---|
| S1 钩子 | L1 全程 | 〔钩子大字两行〕+〔**虚构片：演绎标识，L1+6 起，与钩子同屏**〕 | 〔入场编排〕 | 〔翻页 L1+0〕 |
| S2〔…〕 | L〔…〕 | 〔画什么〕 | 〔轮廓几条、怎么错开、是否上色、上色扩散原点〕 | 〔…〕 |
| S〔M〕收束 + 尾牌 | L〔N〕全程 +〔75〕帧 | 〔尾牌文案〕+〔**转述片：「改编自真实经历」**〕 | 〔…〕 | 〔…〕 |

- **前 3 秒必须抛冲突**，第 3 秒预告价值。
- 视觉节拍平均 ≤8 秒一拍；场景就位后纯静止 ≤5 秒。
- 场景硬切，**切点落在旁白句起点**（天然停顿）。
- 一分钟左右的片子，场景图 **≥9 张**（约每 7–8 秒一张新画）。
- 🔴 **中段不许有纯字帧**：钩子卡与尾牌之外，任何一帧都要同屏可见人物场景。金句卡叠在场景上，对应场景的画面栏写明**留空落位区**。

### 6.0 素材工单（生图归执行体；已备的不许再生成）

**已备素材（复用，绝不重生成）**：

| 路径 | 是什么 |
|---|---|
| `public/voice/` | 旁白母带 + 帧表（已冻结） |
| `public/audio/` | BGM + 音效 |
| 〔角色卡目录〕 | 人物卡 + 逐字身份块——🔴 **场景图一律「参考卡 + 粘身份块」生成，禁重生成已冻结的角色** |

**需生成**：

| 产物 | 画什么（对应场景表） | prompt 依据 |
|---|---|---|
| `public/raw/scene-〔n〕.png` | 〔人物 / 物件 / 构图，对应 S〔n〕〕 | 风格块逐字照抄；含人物的图先粘身份块 |

逐张必写死的四件事（详见 `references/production.md` 第四节）：

- 🔴 **画幅写死 `SQUARE 1:1`**；
- 🔴 **留空写成【百分比矩形的角】+ 主体占比下限**，别写「右下留空」这种模糊话；
- 🔴 **每张 2–3 件环境物 + ≥1 件具体道具**；环境物与主体同一支近黑铅笔线（**禁灰线**），至多一件入蜡笔色；
- 🔴 **跨镜道具写到构造级**（腿是什么型、有没有靠背、有没有窗台，逐个写死），对照镜按「同机位复用」整段复制描述，**不许写「同上」**。

**验收命令与阈值**（照抄进工单）：

| 检查 | 命令 | 阈值 |
|---|---|---|
| 拆图层 | `python3 tools/split_layers.py <图> --outdir public --report` | 线稿 ≥0.5%、上色 ≥0.2%、未归类不异常 |
| 占屏比 | `python3 tools/art_scale_check.py` | ERROR <25% / WARN <35% |
| 弱元素可见度 | `python3 tools/ink_visibility.py <ink图> --box 〔x0,y0,x1,y1〕` | ERROR >120 / WARN >95 |

⚠️ **读图核验先合成白底**——分层靠 alpha，直接预览会骗人。
⚠️ 过了验收再写 `SCENE_ART` + `ART_TIMING`：`fromPct/toPct` 用像素级 alpha 包围盒算（±4 余量），**别目测**。

### 6.1 人物素材（若本片有人物）

- **先定镜头再生图，顺序不能反。**
- 每个镜头至少四层，**人物必须是独立 PNG**；`zIndex` 只决定前后**不保证遮挡**——布局参数（left / top / height / 地面 y / 预期遮挡比例）必须写进本文。
- 需要独立人物 PNG 时才走绿幕线：`python3 tools/dekey.py`（**必须 despill 去绿边**）→ `tools/split_props.py`。验收：透明占比 5%–95%、半透明 <1%、边缘绿残差 <25、**肉眼无绿边**。
- 一致性走人物卡制：参考卡 + 逐字粘身份块 + 一致性声明。**一图 ≤2 个有卡角色，逐张生成不批量。**

## 七、字幕（zIndex 12，`layout="none"`，**不要加 premountFor**）

- **一层，顶部固定**，逐句跟帧表。
- **文本源＝帧表里的行文本，不在文案常量里再抄一份**——两个事实源迟早漂移，而漂移出来的字幕**和耳朵听到的不一样**，抽帧还未必看得出。
- **逐块入场，不是逐字卡拉OK**：按中文标点切块，块间隔 3 帧、每块入场 12 帧。

## 八、混音（全部在 Remotion 多轨 `<Audio>` 内完成，**禁事后 ffmpeg 拼卡点**）

- 旁白：一条母带从 frame 0 铺到底，音量 1.0。
- BGM：基础音量〔0.10〕，末〔24〕帧淡出到 0；成曲有铺垫段就用 `startFrom` 跳过（帧号写表达式）。
- 闪避：音量回调 + clamp 包络，集中写在事件表里。轻事件把 BGM 压到 70%，前 2 帧压、保持 6 帧、12 帧弹回。
- **`gain` 是音效自己的音量，`duck` 是它压 BGM 的深度，两个不是一回事。**
- 母带链（渲染后仅重编音轨）：
  ```
  ffmpeg -i out/〔片〕.mp4 -c:v copy -af "loudnorm=I=-11:TP=-2:LRA=9,alimiter=limit=0.85:level=false" -c:a aac -b:a 192k out/〔片〕-master.mp4
  ```
  之后 `volumedetect` 核验 max_volume ≤ -1.0 dB。

## 十一、验收 + 回报（写进 `RENDER-NOTES.md`，如实记录，**跑挂照记**）

1. `tools/verify.sh --quick` 三项过（契约测试 / tsc / 版本门禁）。
2. `tools/verify.sh` 全量过：渲染 + 母带链 + `ffprobe`（分辨率 / 帧率 / 时长三写核对 / 含音频流）+ `volumedetect`。
3. **抽帧读图（真打开看图，帧号用 T 表达式）**。帧号公式：**≥ 这一帧要验的最晚触发元素的触发帧 + 入场帧数(12) + 2 帧余量**；线稿场景要等**画完**再抽，否则会把画一半的线误判成断线。逐帧列表：
   - 〔L1+50〕：钩子大字 +〔虚构片：**演绎标识在位且不低于字号下限**〕
   - 〔…每个验收帧一行…〕
   - 〔T.total_frames+40〕：尾牌 +〔转述片：「改编自真实经历」在位〕；**无任何 URL / 他站名**
   - 任意帧：人物素材无绿边
   - 🔴 **跨镜道具拼图**：每件跨镜道具裁同名区域**横排并看**，逐张回忆不作数
4. **中文逐字校对每个抽帧（错字一票否决）**；字号最小值核查；安全区核查；上色没糊住线；大字没压住画。
5. 产能记录：每大步起止时刻与耗时、生图调用与重试次数、卡壳点与绕过。
6. **本 SPEC 写错或写漏的地方**——最重要的一条，模板靠它迭代。
7. 渲染产物只留 `out/`，失败的生图原图留 `public/raw/`。

## 十二、只有用户能做的（回报里单列待办）

- **人耳终验**：实听母带——旁白和 BGM 的相对关系、**有没有任何来历不明的持续噪声**、语速够不够慢够不够暖。判据＝**旁白清清楚楚、BGM 若有若无**。
- **视觉终裁**：过一遍抽帧和成片。
- **发布页勾选**：AI 声明、内容声明下拉框、原创声明开关（见 `references/publish-check.md` C 节）。
