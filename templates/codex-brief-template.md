## 执行顺序

1. 读 SPEC 全文，读完再动手。**SPEC 没规定的选择，停下来在回报里问，别自行发挥。**
2. 按 SPEC 第六节的素材工单**逐张**生图（不批量）。每张走验收三关：拆图层 → 占屏比 → 白底读图。
3. 拆层产物写进 `SCENE_ART` + `ART_TIMING`，`fromPct/toPct` 用像素级 alpha 包围盒算。
4. 按 SPEC 换 `theme.ts` 常量、按场景表重写 `Scenes.tsx`。**只许用现有原语拼装。**
5. `tools/verify.sh --quick` 见绿。
6. **改完布局或绘制参数，跑一次 `tools/probe.sh` 读图。**
7. `tools/verify.sh` 全量：渲染 + 母带链 + `ffprobe` + `volumedetect`。
8. 自 QC 抽帧读图，逐条对 SPEC 第十一节。
9. 写 `RENDER-NOTES.md`，**跑挂照记**。

## 硬纪律

- 🔴 **`--quick` 全绿不等于画面是对的。** 类型正确、无硬编码、测试通过的代码照样能把整个场景擦掉、把大字压在人物腿上、把铅笔画成马克笔。**机器判不了的，就得让人看见。**
- 🔴 **中文永不烤进生图。** 片子里所有中文一律走 Remotion 渲染。
- 🔴 **禁止联网下载片内资源。** 渲染浏览器已经在建工程时预装好了，缺什么先在回报里说，别自己下。
- 🔴 **跑完 `git status` 核对工作树**，别留下计划外的改动。
- 生图迭代：1 张 base + 最多 2 轮单点修改，每轮重申不变量清单。超了就换候选，别无限磨。
- 帧号一律写成帧表表达式，**禁手写魔法帧数**。
- 随机值一律 `random(seed)`，**seed 里不许含 frame**。

## 回报要求

- 每张图的生成次数与失败原因；
- 三关验收的实际数值（不是「通过」两个字）；
- 抽帧读图的结论，逐帧逐项；
- **SPEC 写错或写漏的地方**——这一条最重要；
- 卡壳点与你怎么绕过去的。
