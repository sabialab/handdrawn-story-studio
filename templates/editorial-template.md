## 一、这个号是什么

| 项 | 值 |
|---|---|
| **账号名** | 〔逐字写准，会印在每条片子的角标上，错一个字往后全部返工〕 |
| **一句话定位** | 〔做什么内容，用他自己的话，别翻译成行话〕 |
| **给谁看** | 〔多大年纪、什么身份、在什么场合刷到〕 |
| **看完是什么感觉** | 〔希望观众带走的那种情绪〕 |
| **陌生人凭什么看完** | 〔答不上来就写「待定」，往后每条选题会再问一遍〕 |

## 二、故事从哪来

| 项 | 值 |
|---|---|
| **主要走哪类** | 〔亲历 / 转述改编 / 虚构，可多选，写清哪类是主力〕 |
| **素材目录** | 〔他自己记素材的路径；没有就写「暂无，每次现给」〕 |
| **素材使用标记** | 〔用过的段落怎么标，缺省是在段首写「已用于 YYYY-MM-DD」〕 |

**标识规则（不许改写）**：

- 亲历 → 无需特别标注
- 转述改编 → 尾帧「改编自真实经历」
- 虚构 → 开场 3 秒内画面内标识 + 尾牌 + 封面小字；**禁打「真实故事」类标签**

## 三、更新与平台

| 项 | 值 |
|---|---|
| **更新频率** | 〔每周几条 / 每天一条 / 想到就发〕 |
| **目标平台** | 〔只发一家还是多家；只发一家是好事，省掉多平台适配那套复杂度〕 |
| **画幅** | 〔缺省 9:16 竖版 1080×1920〕 |
| **AI 声明入口** | 〔发布页哪个位置；不知道就写「待查」，第一次发布时找出来填回这里〕 |
| **原创声明门槛** | 〔那个平台的最低时长等条件；不知道写「待查」〕 |
| **标题限制** | 〔字数上限、允许的符号；不知道写「待查」〕 |

## 四、受众读得快不快（决定几个缺省值）

| 项 | 缺省 | 本号取值 |
|---|---|---|
| 字幕**行**停留 | **≥2.5s** | 〔双向可调：读得慢往上到 3s，读得快往下到 2.0s；拿不准就留在缺省〕 |
| 短应答停留（≤4 字**且**话说完了） | ≥1.2s | 〔一般不动〕 |
| 画面文字字号下限 | 40px | 〔视力弱就往上抬，别往下降〕 |

这三个数要与 `handdrawn-studio/studio.config.json` 的 `captions` 块一致——**合成脚本读的是那份 JSON**，改了这里没改那里等于没改。

⚠️ 单位是「字幕行」不是「音频句」——对戏必然产生短句，行是由相邻的句子合并出来的。

## 五、声音

| 项 | 值 |
|---|---|
| **说话人** | 〔几个人；一人独白还是对戏〕 |
| **音色 ID** | 〔从 MiniMax 控制台音色列表**复制**，别凭记忆拼——拼错会直接报 voice id not exist〕 |
| **语速** | 〔`studio.config.json` 的 `tts.speed` 是**全局缺省**；对戏时想只放慢其中一个人，用环境变量 `MINIMAX_SPEED_<说话人名>` 覆写，别往 script.json 顶层补 speed〕 |
| **复刻槽** | 〔有就记 ID，并写清源音频留档在哪。槽挂在自己的 key 下，换 key 就没了〕 |
| **BGM** | 〔要不要；要的话基础音量缺省 0.10，判据＝旁白清清楚楚、BGM 若有若无〕 |

机器读的那几项另落 `handdrawn-studio/studio.config.json`，两份要一致。
