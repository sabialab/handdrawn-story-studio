# 示例：两句话 → 一条成片

从两句话素材走到能发的物料，完整一遍。故事是虚构的，人物没有原型，正好顺便演示「虚构必须标演绎」这条怎么落地。

> 📸 **截图占位**：本文的每个 `〔截图：…〕` 标记处，等第一次真实跑完之后补真截图。**在补上之前别说「效果如图」——这里现在只有文字。**

配置假设（首跑访谈已经做完，`handdrawn-studio/editorial.md` 长这样的一部分）：

| 项 | 值 |
|---|---|
| 账号名 | 慢慢画 |
| 定位 | 画家里那些不起眼的小事 |
| 给谁看 | 三四十岁、家里还有老人的人 |
| 故事来源 | 虚构为主，逐条标演绎 |
| 字幕行停留 | ≥2.5s（缺省值没动） |
| 字号下限 | 40px（缺省值没动） |
| 说话人 | 两个：叙述者、奶奶 |

---

## 第一步：丢两句话

用户在对话里说：

> 我奶奶把每个塑料袋都叠成小三角，攒了一抽屉。我以前老笑她。

就这么多。没有结局，没有立意，也不需要有。

---

## 第二步：Agent 出三个候选（提案段）

`handdrawn-studio/drafts/2026-08-09/proposal.md` 里出来三条。这里只摊开被选中的那一条：

### 候选 2 ·《一抽屉小三角》

| 项 | 内容 |
|---|---|
| **故事梗概** | 奶奶把塑料袋叠成小三角攒了一抽屉，「我」一直笑她抠。搬家那天她坐在抽屉前一个个数，挑出最厚的那几个递过来，说这个装书结实。 |
| **忠告芯** | 老人攒的东西，扔之前问一句这是留给谁的。 |
| **故事来源** | 虚构 |
| **素材出处** | 创作（用户口述的生活细节起意） |
| **标识做法** | 开场 3 秒内画面标识 + 尾牌 + 封面小字；禁打「真实故事」类标签 |
| **转发动机** | 实用价值——转给家里也有个「什么都留着」的老人的兄弟姐妹，替他说一句「别嫌我妈啰嗦」 |
| **情绪终点** | 心里一暖 |

| 维度 | 分 | 理由 |
|---|---|---|
| 可送出性 | 5 | 「扔之前问一句这是留给谁的」是一句能直接转给家人的话 |
| 情绪终点 | 4 | 停在暖，不停在唉 |
| 转发动机 | 5 | 谁转给谁很具体：家里有老人的同辈之间 |
| 情感真实度 | 4 | 有塑料袋、抽屉、装书这几个具体的物 |
| 来源可靠度 | 3 | 虚构，标识成本已经算进去 |
| **总分** | **21/25** | 门槛 15，过 |

另外两条被否的：一条是同一个故事换了个标题（不算另一个候选，当场淘汰），一条的忠告芯写成了「要孝顺老人」——**空泛说教不是忠告**，答不出「谁会转给谁」，可送出性 1 分。

用户回了一句「就第二个吧，那句『装书结实』要留着」。→ **人工敲定点①过。**

## 第三步：先把工程建起来，再写旁白稿

**顺序不能反**——待会儿合成出来的音频要落进 `<工程>/public/voice/`，工程不存在就没地方落。

```bash
cp -R $SKILL_DIR/video-template/handdrawn-master video-template/xiaosanjiao
# 清场：删 out/ public/raw/ .media/ 的旧产物，node_modules 删掉重装
cd video-template/xiaosanjiao && npm install && npx remotion versions
npx remotion browser ensure     # 预装渲染浏览器，别等首渲时联网下
tools/fetch_fonts.sh            # cp -R 会把软链展开成真目录，重跑即修复
```

（`$SKILL_DIR` ＝ 本包安装目录，见 `SKILL.md`「路径约定」。本文所有命令都在**项目根**下敲——母版在包里，每片工程在项目根的 `video-template/` 下。）

然后答七问（简报略），再写 `script.json`。按说话人成段，三段：

```json
{
  "voices": {
    "叙述者": "Chinese (Mandarin)_Radio_Host",
    "奶奶": "〔从 MiniMax 控制台复制的女声音色 ID〕"
  },
  "pronunciation": [],
  "runs": [
    {
      "id": "R1", "who": "叙述者", "gap_after": 700,
      "tts": "我奶奶叠塑料袋，叠成小三角，一抽屉。<#0.4#>我以前老笑她，超市门口一块钱三十个。",
      "show": "我奶奶叠塑料袋，叠成小三角，一抽屉。我以前老笑她，超市门口一块钱三十个。"
    },
    {
      "id": "R2", "who": "奶奶", "gap_after": 900,
      "tts": "一块钱三十个。<#0.5#>可你真要用的时候，手边一个都没有。",
      "show": "一块钱三十个。可你真要用的时候，手边一个都没有。"
    },
    {
      "id": "R3", "who": "叙述者",
      "tts": "去年我搬家。<#0.4#>她坐在抽屉前面一个一个翻，挑出最厚的那几个递给我，说这个装书结实。<#0.6#>我才明白，她攒的不是袋子，是省着给我用的。",
      "show": "去年我搬家。她坐在抽屉前面一个一个翻，挑出最厚的那几个递给我，说这个装书结实。我才明白，她攒的不是袋子，是省着给我用的。"
    }
  ]
}
```

几个地方值得看一眼：

- **稿子里没有 `model` / `speed` / `default_gap`**——那三项是账号层面的设置，写在 `handdrawn-studio/studio.config.json` 里（`tts.model` / `tts.speed` / `tts.defaultGapMs`），不逐集重复。
- **R2 的 `gap_after` 是 900 不是缺省的 700**——奶奶说完那句之后要留一段空，接下来才是「去年我搬家」的转场。段间停顿走拼接，误差为零。
- **`<#0.4#>` 不是 400 毫秒**，实际间隔大约是 `430 + 1000×0.4 ≈ 830ms`。写的时候按这个算，别照字面值理解。
- **结尾没有「你家也有这样的老人吗」这句**。它会放在描述里，不放旁白——旁白讲完就停。
