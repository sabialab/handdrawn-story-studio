# 日常流程 · 提案段

**做什么**：把用户给的素材变成 3 个可选的候选，交他敲定。
**不做什么**：不写稿、不出片。**停在敲定点上。**
**产出**：`handdrawn-studio/drafts/<日期>/proposal.md`（模板 `templates/proposal-template.md`）。

前置：`handdrawn-studio/editorial.md` 已存在。没有就先去 `interview.md`。

## 第一性原理：这条能不能被当成一件礼物送出去

先记住这一句，后面所有判据都从它派生：

> **「这段话送给你」成立 → 能转。「这是我的感受」→ 转不出去。**

同样是手绘故事片，同样的画风、同一个账号、同一周发出去，一条带着「可以转给家里人的一句忠告」，一条只是「一个让人难过的故事」，转发能差出一个数量级。前者观众会说「送给你」，后者观众只会说「我也是这样」——**后者换来的是评论，不是转发。**

做法一句话：**故事是壳，忠告是芯。** 封面和前三秒给故事钩子，描述和结尾给那句能带走的话。

判据可以机械核：写完问自己一句——**用户会把这条转给谁？代替他说了哪句话？** 答不出来就是答不出来，别糊过去。

## 步骤

### 1. 读配置

`editorial.md` 的定位、受众、永久不碰的题材，这一趟全程压着它做。

### 2. 收素材

按优先级：

1. 用户这次给的一两句话；
2. 用户直接点的题；
3. `editorial.md` 里记的素材目录（他自己记的生活片段、家人讲过的事）——**标了「已用过」的段落不再当新故事内核**，同一段记录里没用过的别的细节仍可用；
4. 公开可考的素材（老物件、旧制度、当年的物价这类）。

**素材空了就说素材空了。** 宁可这天不发，也别拿同一个模板换个名字换个地点再灌一条——这正是各平台「批量发布近似情景、文案、元素的同质化内容」那条规则盯着的东西，而用 AI 管线日更故事天然离它很近。

### 3. 查重（两重，缺一不可）

**常规查重**：近 30 天已发布的选题和标题、以及否决过的选题。撞了即淘汰。

**同质化查重（更重要）**：按「**情景 + 冲突 + 结局**」三元组比对近 30 天全部片子。三元组撞了即淘汰，**换个名字换个地点不算改**。

**比对材料在哪**：本包 v1 没有独立台账（README「v1 没做的事」有记），查重面＝`handdrawn-studio/drafts/` 里此前各期的 proposal 与发布记录，逐份翻。刚起号没有存量时这一步空跑，**明说「无存量可查」**，别写成「查重通过」——没查和查过没撞是两回事。

⚠️ **画风一致 ≠ 情景雷同。** 画风必须保持一致（多数平台判定原创时，创作风格和垂直程度是裁量输入，换来换去等于主动把裁量搞脏）；但情节结构必须真的不同。这两件事别混。

### 4. 故事来源分类（每个候选必须落定，不许含糊）

| 类别 | 定义 | 标签 | 画面标识 |
|---|---|---|---|
| **亲历** | 用户本人经历 | 「真实故事」类标签可用 | 无需特别标注 |
| **转述改编** | 家人朋友口述、公开可查的真实事件改编 | 「真实故事」类标签可用 | 尾帧「改编自真实经历」 |
| **虚构** | 创作的故事 | **禁用「真实故事」类标签** | **开场 3 秒内画面内标识**（≥40px）+ 尾牌 + 封面小字 |

判据：**观众会不会以为这是创作者本人的真事。** 会 → 按亲历 / 转述标；不会 → 虚构。第一人称叙述天然指向亲历或转述，**虚构故事用第一人称就必须标演绎**。

为什么虚构片的画面标识要放在开场 3 秒而不是只放尾帧：标识是为了避免观众误解，那它就该出现在观众**可能产生误解之前**。片子播了 40 秒观众才在尾帧看到「本故事为演绎」，前面 40 秒的误解已经发生了。

### 5. 五维评分（各 1–5 分，总分 ≥15 才进提案）

| 维度 | 问自己 |
|---|---|
| **可送出性**（首维） | 这条能不能被当成一件礼物送出去？用户会说「送给你」还是「我也是这样」？答不出「他会转给谁、代替他说了哪句话」＝ **1 分，淘汰** |
| **情绪终点** | 停在哪种情绪上？敬佩 / 义愤 / 心里一暖 / 命运感 / 警醒 → 加分；纯悲伤、纯遗憾、空泛说教 → 减分 |
| **转发动机** | 具体到「谁转给谁、为什么」。答不上来即 1 分 |
| **情感真实度** | 有没有具体的物、具体的对话、具体的场景？还是一堆形容词？ |
| **来源可靠度** | 亲历 > 转述改编 > 虚构。虚构不扣分，但**标识成本要算进去** |

**合规安全单列，不打分，一票否决**：踩了 `editorial.md` 里写死的永久不碰题材，或者踩了 `publish-check.md` 的通用红线 → 整条淘汰，不进提案。

**门槛硬条件（缺一不可）**：

1. 可送出性 ≥4 分；
2. 转发动机说得出「谁转给谁」；
3. 故事来源已落定；
4. 过了同质化三元组查重；
5. 没踩任何一条永久不碰。

### 关于情绪终点的两句实话

**排序是可信的**：让人「哇」「了不起」「太气人了」的片子，通常比让人「唉」的跑得远。

**但它不是定律，只是先验**。悲伤本身不必然降低传播，也不该一票淘汰它——真正杀死一条片子的不是悲伤，是**它不是一件可以送人的东西**。所以情绪终点在评分表里是次维，可送出性才是首维。

**这个赛道最大的陷阱**：手绘情感故事的默认引力就是催泪，而催泪的片子**在提案纸上「感觉最好」**。别心软的对象不是「停在唉的」，是「送不出去的」。

### 转发的三种动机（每条至少命中一种，写进提案）

| 动机 | 定义 | 怎么用 |
|---|---|---|
| **实用价值** | 能帮自己或家人留住有用的信息 | **首选。** 故事是壳，忠告是芯——一条能转给家人的提醒 |
| **情绪态度** | 能帮用户说出自己的心声 | 得把「心声」写成**一句可以替对方说出口的话**，那时它才变成礼物；否则只换来评论 |
| **社交人设** | 能帮用户塑造想呈现的形象 | 打折使用。它在有些人群上很灵，在另一些人群上几乎不成立，别把宝押在这里 |

### 6. 产出提案

`handdrawn-studio/drafts/<日期>/proposal.md`，**3 个候选**，每个含：

- 故事梗概（一段话讲完）
- 忠告芯——那句能被带走的话，逐字写出来
- 故事来源分类 + 素材出处
- 转发动机（谁转给谁、为什么）
- 情绪终点
- 五维评分表 + 总分
- 标题草案
- 前 3 秒钩子草案
- 画面可拆性初判（这个故事能不能拆成 8–10 个画面）
- 合规自查 + 查重结论

**三个候选要真的不一样。** 同一个故事换三种标题不叫三个候选。

## 停在这里

把三个候选摆给用户，等他选。他全否了就重来一轮，别劝他将就一个。

他选完之后，在 `proposal.md` 里记一个敲定标记，再进 `narration.md`。
