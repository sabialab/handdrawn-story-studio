# 出片流程

**做什么**：把冻结好的旁白变成一条渲染出来的成片。
**分工铁律**：**你只写单，不生图，不代跑用户的桌面端。** 你交两样东西——①旁白音频和帧表 ②一份执行单（SPEC + codex-brief）。生图、拆图层、改常量、渲染、自检，全部由执行体按单干。

**本文第一节排在写旁白稿之前**（音频要落进工程里），第二节往后排在用户听过样带点头之后。

## 一、工程从母版复制起步（**先做这个，再写旁白稿**）

```bash
cp -R $SKILL_DIR/video-template/handdrawn-master video-template/<新片 slug>
```

（`$SKILL_DIR` ＝ 本包安装目录，见 `SKILL.md`「路径约定」；命令在**项目根**下敲。）

**工程一律建在项目根的 `video-template/` 下**，不是包里——母版在包里、每片工程在项目根，这两处不是一个地方。共享字库目录与 `public/fonts` 的相对软链都按这个布局算：软链是 `public/fonts -> ../../assets/fonts`，从 `video-template/<新片 slug>/public/` 往上跳两级，解析出来正是**项目根的 `video-template/assets/fonts`**。所以新工程必须直接放在 `video-template/` 下，挪一层软链就断。首次建工程后跑一次 `tools/fetch_fonts.sh`，字库就落进项目根的 `video-template/assets/fonts`，同一项目里各片工程共用这一份。

复制之后清场：

1. 删 `out/`、`public/raw/`、`.media/` 里的旧产物；
2. `node_modules` 删掉重装。`npm install` 之后跑 `npx remotion versions`，必须报 "All packages have the correct version" 才继续；
3. 跑 `tools/fetch_fonts.sh`（幂等）。
4. **把访谈产出的配置拷进工程**：
   ```bash
   cp handdrawn-studio/studio.config.json video-template/<新片 slug>/public/studio.config.json
   ```
   两个消费方读的不是同一份：合成脚本从**项目根**的 `handdrawn-studio/studio.config.json` 读（TTS 音色/语速/字幕下限），引擎的品牌角标是构建时从**工程内** `public/studio.config.json` 读的——不拷这一步，`cp -R` 带过来的是母版缺省值，成片角标永远是占位「你的账号名」。

⚠️ **`cp -R` 会把软链展开成真目录**，重跑 `fetch_fonts.sh` 即修复。软链**必须是目录级**（`public/fonts -> ../../assets/fonts`）。逐个文件建软链、又照抄目录级的相对路径，会少跳一级——症状是 **tsc 和契约测试全绿，一渲染就字体 404**。

⚠️ **新工程 `npm install` 不带渲染用的浏览器**，首次渲染会静默联网下 90 多兆。建工程时先跑 `npx remotion browser ensure` 预装，否则执行单里那条「禁止联网下载」的纪律会跟它撞车。

## 二、常量换在哪（母版是单一事实源）

`src/theme.ts` 是唯一要大改的代码文件。**任何组件里都不许出现硬编码的文案、色值、帧数。**

| 常量块 | 换不换 | 说明 |
|---|---|---|
| `STORY_SOURCE` | **必换** | 三类之一：`firsthand` / `adapted` / `fiction`。标识动作由它机械派生（虚构 → 开场标识，转述 → 尾帧标识），**别只写在 SPEC 里** |
| `COPY` 全部 | **必换** | 钩子、尾牌、角标，逐字来自本片 SPEC |
| `COPY.sourceMark` | **永不换** | 「本故事为演绎」「改编自真实经历」是红线用语，不许改写 |
| `SCENE_ART` + `ART_TIMING` | **必换** | 本片拆层场景。`fromPct/toPct` 用像素级 alpha 包围盒算（±4 余量），**别目测** |
| `TOKENS`（颜色 / 字体 / 字号 / 阴影 / 层级） | **永不换** | 视觉 token 是风格签名，逐字照抄禁近似值。需要新字号可以加键，**不改旧值，不降到下限以下** |
| `MOTION` | **永不换** | 线条绘制、错开起画、蜡笔填充、慢推、字幕逐块——这就是手绘风的动效签名 |
| `FRAMES` + `SCENE_RANGES` | **必换** | 场景锚随新帧表重排，表达式语法不许变 |
| `LAYOUT` 的舞台 / 钩子 / 尾牌 / 标识坐标 | **必换** | 这几个数是**咬合**的，改一个要重算相邻的 |
| `ASSETS.audio` / `SFX_EVENTS` | **必换** | 指向本片素材，结构不动只换值 |

`src/Scenes.tsx` 是唯一按分镜重写的组件文件，**只许用现有原语拼装**。其余组件一行不动。

## 三、工程铁律（AI 写 Remotion 的通病清单）

1. 所有动画只用 `useCurrentFrame()` 驱动，每个 `interpolate` 都带双向 clamp；**一次性事件必须加 `frame >= 触发帧` 门控**——clamp 会把事件值钉在触发之前，画面上就是「还没到就已经发生了」。
2. 随机值一律 `random(seed)`，禁 `Math.random()` 和 `Date.now()`。**seed 里不许含 frame**，含了就是每帧重掷，线会抖成筛子。
3. **禁 CSS transitions / animations**，seek 不安全。
4. 重场景用 `<Sequence premountFor={30}>`；资源一律 `staticFile()`。
   ⚠️ `premountFor` 只存在于 absolute-fill 布局变体，`<Sequence layout="none">` 上没有这个属性——字幕那类序列硬加会报 TS2322，**这不是 bug，别「修」**。
5. 中文字体走本地完整字库，**禁 `@remotion/google-fonts`**（每次渲染要发近三百个网络分片请求）。
6. 版本一律精确锁，禁用 caret。改了 `package.json` 必须同步 lockfile。
7. 画布不是网页：内容占满画面（两侧留白别超过 200px、纵向填充 70% 以上），不够就放大字号，**不许加内容凑**。

## 四、素材工单（SPEC 第六节，写单是你的活）

**先定镜头再生图，顺序不能反。** 同一个人物在全景和特写里的大小、位置、朝向都不同；先随便生成一堆素材，后面必然出现比例错、视线反、主次不清。

每张图的单要说清三件事：**画什么**（对应场景表）、**prompt 依据**（风格块逐字照抄）、**验收阈值**（照抄下面的数）。

### 4.1 画面密度与丰富度

- 视觉节拍（新场景起笔、金句字卡入场各算一拍）**平均 ≤8 秒一拍**；场景就位后的纯静止 ≤5 秒（缓推 1.0→1.05 不算一拍）。
- 一分钟左右的片子，场景图 **≥9 张**（主场景 + 元素批合计，约每 7–8 秒一张新画）。
- 每张 **2–3 件环境物 + 至少 1 件具体道具**。环境物和主体用**同一支近黑铅笔线**（🔴 禁灰线——拆层脚本按颜色分层，灰线会落进「未归类」挤爆阈值），至多一件入蜡笔色，留白签名不破。
- **加密度的手段按顺序**：拆句配画（一句一画）→ 场景内元素分批起笔 → 金句字卡当一拍用。**每一拍都要着床在旁白语义上——为凑密度硬切画面就是注水。**
- 🔴 **中段不许有纯字帧**：片头钩子卡和片尾尾牌之外，任何一帧都不能是「只有文字、没有人物画面」。中段的金句卡必须叠在含人物的场景上，**场景工单要预先给卡留出落位区**。

### 4.2 画幅和留空要写死，别给形容词

🔴 **画幅逐张写死 `SQUARE 1:1`。** 画面是 `objectFit: contain` 塞进舞台的——方图上屏面积接近舞台的九成，横图只有六成。不写画幅，模型自己挑，挑出来的长图**画得再满也天然小一号**。

🔴 **「留空」必须写成【百分比矩形的角】+ 主体占比下限。** 写「右下留空」这种模糊话，模型的省事解法是**把整条边空出来、主体整体缩小**——留空成立、红线全过、拆层阈值全绿，唯独人小得看不清。正确写法三句：

1. `FILL THE CANVAS` + 主体跨度下限（如「人物加道具不少于画布宽度的一半，头在上三分之一」）；
2. 留空区写**具体百分比矩形**（如「宽 62%→100% × 高 69%→100% 的右下角」）+ 一句 `It is a CORNER, not a whole side`；
3. `Do NOT shrink the drawing to create empty space — a small drawing floating in a large empty canvas is a FAILED image`。

⚠️ 留空矩形要按元素在屏幕上的真实占位反推（量一帧探针图，别拍脑袋）。画幅一换，百分比就得重算。

### 4.3 跨镜的东西要写到构造级

「同一张方桌」「同一条板凳」这类跨镜约束，**只写名字必然翻车**——生图每一镜都会重新发明一遍构造。实录里出现过：方桌四镜同款、唯独一镜没画腿桌面悬空；木格窗三镜三个样；板凳三种型号，其中一种长出了靠背。**这些全部通过了机器验收——机器判不了「是不是同一张」。**

写单三条：

1. **每件跨镜道具写死构造，别写名字。**
   ✅「方桌：四条**方形直腿**、厚板桌面，**每一镜都要把四条腿画全并落地**」
   ❌「方桌」「同一张方桌」
   「有没有靠背」「有没有窗台」「腿是什么型」这类**二值特征必须逐个写死**——缩略图上读得出的差别就这几处。
2. **对照镜按「同机位复用」写单。** 「S8 是 S2 的对照镜，只有人少了」不够，生图会当成两个独立场景各画一遍。要写成「机位、家具位置、窗的位置与格数、桌上餐具数量与 S2 **逐项相同**，唯一差异＝人物从 N 人减到 M 人」，并把 S2 的构造描述**整段复制**过来，**不许写「同上」**。
3. **别在单里自相矛盾。** 总则说「方桌五镜全部入土黄」、后面又写「S5 方桌留白」，执行者只能猜。总则里就写「除 S5 外」。

**验收纪律**：跨镜道具**必须裁下来拼成一张图并排看**。分开看每一张都「像那个东西」，拼一起才发现是三个东西。🔴 **这项机器判不了，执行者自己写的「已自检」不作数，你必须独立做一遍。**

### 4.4 背景弱元素要给可见度下限

工单点名「门外两个看不清脸的身影」这类淡元素时，`vague / faint / only outlines` 这些词**把可见度整个交给了抽卡**。实录里两张图措辞逐字相同，一张读得出、一张在正常观看下完全读不出来，而设计里那个「对照」的支点因此缺了一半。

正确写法两句：①正面描述线条深度（「与旁边的门框、窗框**一样深、一眼可读**」）②把「看不清脸」和「看不见」**拆开写死**（`clearly readable outlines` **和** `NO facial features` 同时要，再补一句「加深不等于加脸」）。

### 4.5 生图的固定骨架

```
Subject: {画什么},
loose hand-drawn pencil sketch, visible hand wobble in the lines, isolated subject.
Colors: near-black pencil outline (#2B2B28) on warm white paper (#FFFDF8);
partial crayon hatching that is NOT filled in — muted blue (#4A7FB5) / green (#5B8C3E) /
warm red (#D94F3D) / ochre (#D9A441) / brown (#8B5A3C), most of the paper left bare.
Style: simple line drawing, calm and restrained, not cute-exaggerated, not photorealistic,
no 3D, no gradients, no drop shadows. Transparent background PNG.
Constraints: absolutely no text, no letters, no numbers, no Chinese characters,
no logos, no watermark, no URL, no QR code.
```

- **负向清单每条必带。**
- 🔴 **中文永不烤进生图。** 生图模型画不对中文，而且字幕轨用的字库是挑过的——烤进生图等于既爆字又丢字库。片子里所有中文一律走 Remotion 渲染。
- 色值上，**别指望生图命中 hex**。校色发生在 Remotion 层（`theme.ts` 的常量），素材只提供形状和笔触。生图不命中 hex 本来就不算缺陷。

### 4.6 验收阈值（照抄进工单）

| 检查 | 命令 | 阈值 |
|---|---|---|
| 拆图层 | `python3 tools/split_layers.py <图> --outdir public --report` | 线稿层 ≥0.5%、上色层 ≥0.2%、未归类不异常 |
| 画得够不够大 | `python3 tools/art_scale_check.py` | ERROR <25% / WARN <35% of stage |
| 弱元素可见度 | `python3 tools/ink_visibility.py <ink图> --box x0,y0,x1,y1` | ERROR >120 / WARN >95（最暗 2% 均值） |
| 绿幕抠图（仅人物需要独立 PNG 时） | `python3 tools/dekey.py` → `tools/split_props.py` | 透明占比 5%–95%、半透明 <1%、边缘绿残差 <25、肉眼无绿边 |

⚠️ **读图核验先合成白底**——分层靠 alpha，直接预览会骗人，看起来跟原图一模一样。

⚠️ 这三个脚本**各管各的一格**：拆层只管「线稿和上色分不分得开」，占比检查只管大小不管深浅，可见度检查要人给包围盒所以是逐元素的一次性核查。**三个都绿不等于画面是对的。**

## 五、角色一致性：给角色捏一张卡

**单张头像不是人物卡。** 每次凭文字重新描述人物就是抽卡——实录里，引用了完整参考图的角色跨场景很稳，引用单张头像特写的那个直接被画成了另一个人。病根是单张头像没有全身比例、多角度、姿势信息，模型只能自行发挥。

### 卡长什么样

一人一卡一张方图，暖白纸底分区排版，**卡内所有格子必须是同一个人**，每格配一个短英文标签（帮模型绑定语义，也帮你逐格验收）：

| 区 | 内容 |
|---|---|
| **主区 · 转身**（左半，约占卡面一半） | 全身 4 视图：正面 / 四分之三 / 侧面 / 背面，同一基线同一身高，中性站姿；最左侧一条淡色头身比刻度 |
| **表情区** | 4 个头像，克制的那几种（平静浅笑 / 关切 / 微讶 / 欣慰）——不给夸张模板，模型就不会画咧嘴大哭大笑 |
| **头部角度区** | 4 个头像：四分之三 / 侧 / **微低头（看手里的东西）**/ 正面。低头是高频机位，卡上没有模型就现编 |
| **细节放大区** | 3 格特写：发型侧后 / 领口与扣子 / 鞋。简笔风里承载身份的就这几处 |
| **姿势区**（底行） | 4 个高频动作：坐、走、双手递物、手部特写 |
| **角落标注** | 色板（衣服、腮红的 hex 小方块）+ **拉丁字母名牌**。**卡上文字只许拉丁字母**——生图模型画不对中文 |

### 怎么捏、怎么冻

1. 先写设定：身份、年龄、性格、禁忌，外加一段**逐字身份块**（英文，场景图里要原样粘贴的那段）。
2. 出卡。已经有可信形象的（头像、验收过的参考图）作为参考图喂进去，**卡必须长在它上面，不许另起炉灶**。
3. 三关验收：①脸型五官、画风、服装三点对得上身份源 ②**卡内自一致**——所有格子是同一个人（转身高度对齐、表情不换脸、姿势不换衣）③网格齐全、名牌和色板在位、无中文。
4. 过了让用户点头，然后**冻结入库，禁止重生成**。重新生成等于换脸，而多数平台判定原创时创作风格是裁量输入。改设定（换发型、换衣服）＝用户拍板 + 重做卡 + 记一笔，不许「顺手改」。

### 场景图怎么引用卡

```
[参考图：出场角色的卡（多人就给多张）]
+ [每个角色的身份块，逐字粘贴，禁改写禁概括]
+ [本场景：动作 / 构图 / 道具，只写这一场的事]
+ [风格铁律块，逐字]
+ [一致性声明：Keep the EXACT same face, hairstyle, outfit, age and proportions
   as each character's reference sheet — same person, no identity change.]
+ [负向清单]
```

纪律：

- **身份块每次逐字重复。** 一致性来自重复，不来自模型的记忆。
- **一张图最多 2 个有卡角色**；多场景逐张生成，不批量（批量会互相带偏）。
- **1 张 base + 最多 2 轮单点修改**，每轮重申不变量清单。超了就换候选，别无限磨。
- **路人不用卡。** 无名的邻居、路人可以当背景出现，画得泛化、不给特写、一张图不超过 2 个，逐片长相不同不算缺陷。一旦这个角色有名字、会再出场，回到卡制。
- **卡提高的是底线和命中率，不是免检。** 每张场景图仍要走三点一致性验收。

## 六、SPEC 和执行单

SPEC 从 `templates/spec-template.md` 复制填实，占位槽全部填完。执行单从 `templates/codex-brief-template.md` 填。

**执行单随当天的 drafts 走，工程目录不留副本**——两处副本迟早漂移。

执行单里必须写明的几句：

- 改完场景组件或常量之后，**跑一次探针读图**。`tools/verify.sh --quick` 全绿不等于画面是对的：移植当天三个缺陷全是「类型正确、无硬编码、测试通过」的代码——填充把整个场景擦掉了、场景大字压在椅子腿上、线条粗成了马克笔。**机器判不了的，就得让人看见。**
- 执行体如果有写工作区的权限，**跑完 `git status` 核对工作树**。
- 禁止联网下载片内资源（渲染浏览器已经在建工程时预装好了，这句要写清楚，否则会撞车）。

## 七、验收

这三条**在工程目录里敲**（`video-template/<新片 slug>/`），不是在项目根，也不是在包里：

```bash
tools/verify.sh --quick   # 契约测试 + tsc + 版本门禁，秒级，写代码期间随手跑
tools/probe.sh            # 本片素材还没到位时渲静帧读图（造静音占位，渲完即删）
tools/verify.sh           # 全量：渲染 + 母带链 + ffprobe 判定 + 抽帧
```

### 抽帧读图（成片交回后你自己做，机器不能代）

抽帧帧号的通用公式：**≥ 这一帧要验的最晚触发元素的触发帧 + 入场帧数 + 2 帧余量**。手绘特化：线稿场景要等**画完**再抽，否则抽到画一半的线，读图会误判成「线断了」。

逐条核：

- **中文逐字校对——错字一票否决**
- 字号最小值核查（不低于配置里的下限，尾帧小字也不例外）
- 安全区：画面上下各留出的那一段里没有关键内容
- **虚构片：演绎标识在开场 3 秒内，且不小于字号下限**
- **转述改编片：尾帧「改编自真实经历」在位**
- 账号角标在位
- 画面无外链、无二维码、无他站账号名
- 线画完了没断，上色没糊住线，大字没压住画
- 场景丰富度对照工单达标；中段没有纯字帧
- 🔴 **跨镜道具拼图并排看**（第 4.3 节）

### 机器核

`ffprobe` 核分辨率、帧率、时长、含音频流；母带链之后 `volumedetect` 核峰值不削波。

### 只有用户能做的

- **人耳终验**：实听母带——旁白和 BGM 的相对关系、**有没有任何来历不明的持续噪声**、语速够不够慢够不够暖。判据一句话：**旁白清清楚楚、BGM 若有若无。**
- **视觉终裁**：他过一遍抽帧和成片。
- 发布页的那几个勾选（见 `publish-check.md`）。

## 八、封面

**封面等成片，不前置。** 必须用**本片的手绘素材**（工程里生成的场景图、上色层、人物 PNG）合成，不拿与片子无关的图凑。

- 与视频同比例（多数平台的封面裁切框是锁死的）。
- 缩到 180px 宽还能一秒读出主体——读不出就重做。
- 虚构片的封面小字标识在位。

## 九、没有 Codex 怎么办

SPEC 和执行单照出，交给用户手边任何能跑 Remotion 的 Agent。执行单是一份纯文本的活儿清单，不绑定执行体。

母版自带的 `tools/verify.sh` 那条本机路径一直是通的：装依赖、拉字库、渲染、母带链、抽帧，全在里面。执行体换了，验收标准一个字不改。
