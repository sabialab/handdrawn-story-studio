# 发布前自查清单

**什么时候用**：成片和封面都到手了，交发布物料之前。
**怎么用**：逐条核，**每一条都要有一个具体的证据**（哪一帧、哪一行文案、哪个文件）。写「已过」不作数。

> v1 没有把这份清单做成脚本。原来那套机器守门跟我们自己的仓库结构绑得太死，搬过来会水土不服。所以这一段现在靠人核——**核的时候老实点，别给自己放行**。

## A. 故事来源与标识（最硬的一条）

- [ ] 故事来源三分类已落定：亲历 / 转述改编 / 虚构，写在 SPEC 第〇节，也写进了 `theme.ts` 的 `STORY_SOURCE`
- [ ] **虚构片**：开场 3 秒内画面上有演绎标识，字号不低于下限；尾牌再标一次；封面小字标一次
- [ ] **虚构片**：描述和话题里**没有**「真实故事」类标签
- [ ] **转述改编片**：尾帧「改编自真实经历」在位
- [ ] 标识用语一字未改（`COPY.sourceMark` 是红线用语，不许改写）

判据再说一遍：**观众会不会以为这是创作者本人的真事。** 会 → 按亲历 / 转述标；不会 → 虚构。虚构故事用第一人称讲，就必须标。

## B. 互动与诱导

- [ ] 结尾要的是**观点**，不是祝福 / 点赞 / 关注
- [ ] 描述里没有「转发保平安」「不转不是中国人」这类话
- [ ] 置顶评论、评论区回复跟正文同一套标准——**索赞禁令在评论区同样管用**
- [ ] 没有拿福利换转发（给了转发理由可以，拿福利要挟不行）

**界线一句话**：「你家也有这样的事吗？A 有 B 没有」＝给了讨论理由，可以；「给老人点个赞祝她健康」＝拿故事换点赞，不行。

## C. 平台声明与勾选

- [ ] 发布页的**「AI 生成 / 合成内容」声明已勾**

这是发布页的勾选项，不是文案表述——跟「对外文案里不写 AI 创作」那条不冲突，两件事各管各的。多数平台把它当强制义务，不勾会被系统补标并影响推荐。

- [ ] 内容声明类的下拉框已按你那个平台的规则选好。**有些平台的「AI 制作」和「剧情演绎」是同一个下拉框的互斥选项，只能选一个**——真碰上二选一，选「AI 制作」那类（它通常是法规义务，而下拉框是唯一的履行入口），虚构片的显著标识由**片内三处**独立扛住。⚠️ **这时片内的演绎标识不再是双保险的一半，是唯一路径，绝对不能省。**
- [ ] 原创声明开关：出现就勾。没出现就记一笔，下次发布再看

## D. 画面

- [ ] **中文逐字校对过，零错字**（错字一票否决）
- [ ] 画面上任何文字都不低于字号下限，尾帧小字也不例外
- [ ] 安全区干净：画面上下各留出的那一段里没有关键内容
- [ ] 零外链、零 URL、零二维码；不出现他站账号名或平台名
- [ ] 账号角标在位，逐字正确
- [ ] 没有彩色 emoji
- [ ] 跨镜道具拼图并排看过，是同一件东西

## E. 题材

- [ ] 没碰需要资质的题材（医疗、健康、保健品、荐股这类）
- [ ] 没碰灰产、擦边
- [ ] 没碰迷信、祈福、算命、改运
- [ ] 没有恐吓 / 焦虑式表达（「不看就晚了」这类）
- [ ] 不承诺、不暗示保证收益或效果
- [ ] 没踩 `editorial.md` 里写死的「永久不碰」清单

## F. 同质化

- [ ] 本片的「情景 + 冲突 + 结局」三元组，跟近 30 天已发的都不一样
- [ ] 故事内核来自新的素材源，不是同一个模板换名字换地点
- [ ] 画风一致（这是好事，别为了「不重复」去换画风）

**画风一致 ≠ 情景雷同。** 画风必须稳，情节必须真的不同。这两条不打架。

## G. 交付物齐了没有

- [ ] 母带落盘，命名规范，分辨率 / 帧率 / 时长核过
- [ ] 封面落盘，与视频同比例，用的是本片手绘素材，缩到 180px 还读得出
- [ ] 标题写好了（长度和符号限制按你那个平台的规矩来）
- [ ] 描述写好了，**钩子压在前 20 字**——信息流里通常只显示两行
- [ ] 话题数量没超
- [ ] 置顶评论文案已经写好（**写稿段就填好，别等发布时现编**）

## H. 交给用户之前

把物料按「从上到下照着做」的顺序摆给他：传片传图 → 粘标题 → 粘描述 → 勾选。正文块必须是能直接粘贴的干净纯文本，**不许带任何编辑器的私有语法**。

然后老实说一句：这份清单里哪几条是你核过的，哪几条只有他本人能核（人耳终验、视觉终裁、发布页那几个勾选）。

**别把只有他能做的事，混在你的「已自检」里报过去。**
