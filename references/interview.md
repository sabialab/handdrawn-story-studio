# 首跑定位访谈

**触发条件**：当前项目根没有 `handdrawn-studio/editorial.md`。
**产出**：`handdrawn-studio/editorial.md`（人读）+ `handdrawn-studio/studio.config.json`（机器读）。
**只做一次。** 做完停下来让用户过目，别顺手接着做选题。

## 怎么问

一次问一组，别把十几个问题一口气甩出去。每组问完把用户的回答复述一句确认，再问下一组。

用户答不上来的，给两三个具体选项让他挑，别让他对着空白发挥。他说「都行」「你看着办」的，**不要自己填一个默认值就过去**——那份配置后面每天都在用，填错一个字段，错的是往后每一条片子。填不出来就在字段里写「待定」，并告诉他哪天想清楚了改哪一行。

访谈全程用他自己的话记，别翻译成行话。他说「就拍我家那点事」，就写「拍我家那点事」，别写成「聚焦家庭生活场景的情感叙事」。

## 六组问题

### 第一组：这个号是什么

- 你打算做什么内容？一句话说清。
- 给谁看？他们多大、在什么场合刷到你的片子？
- 你想让人看完是什么感觉？

**追问一句**：「陌生人凭什么看完你这一条？」答不上来不要紧，记下来，往后每条选题都会再问一遍这句。

### 第二组：账号名

- 账号叫什么？

这个名字会印在**每一条片子**的角标上，签名式的，全片常驻。所以要拿准确的写法——错一个字，往后所有片子都得返工。让他逐字确认一遍。

### 第三组：故事从哪来

三类，问他主要走哪类，也可以三类都用：

| 类别 | 是什么 | 标注要求 |
|---|---|---|
| **亲历** | 他本人经历的 | 不用特别标 |
| **转述改编** | 家人朋友讲的、公开可查的真事改编 | 尾帧标「改编自真实经历」 |
| **虚构** | 他编的 | **开场 3 秒内画面上就要有演绎标识**，尾牌再标一次，封面小字标一次；**禁打「真实故事」类标签** |

**这一条要跟他讲清楚，不能一带而过**：编的故事可以做，但必须标演绎。判据是「观众会不会以为这是你本人的真事」——虚构故事用第一人称讲（「我表姨」「我同学」），就必须标。

再问：他自己的素材放在哪个目录？（比如平时记的生活片段、家里人讲过的事。）路径记进 `editorial.md`，往后提案段直接去那儿翻。没有就写「暂无，每次现给」。

### 第四组：更新频率与平台

- 打算多久更一条？
- 发到哪个平台？只发一家还是多家？
- 画幅要什么比例？缺省是 9:16 竖版 1080×1920。

**只发一家的话，直说这是好事**：多平台意味着每条片子要过好几套字数规范和几条母带分流，那套复杂度是被多平台逼出来的，一家不必背。

顺手问一句：他知道自己那个平台的「AI 生成 / 合成内容」声明在发布页哪个位置吗？不知道就记一条待办，第一次发布时找出来，记回配置里。

### 第五组：受众读得快不快

这一组决定几个数，问法要具体：

- 你的受众看视频是什么状态？边干别的边看，还是坐下来认真看？
- 他们视力怎么样，会不会嫌字小？

按回答定这三个缺省值（**都是缺省值，不是铁律，后面随时能改**）：

| 项 | 缺省 | 往哪边调 |
|---|---|---|
| 字幕**行**停留 | **≥2.5s** | 双向可调：受众年纪偏大、读得慢 → 调到 3s；受众读得快、习惯高信息密度 → 下调到 2.0s |
| 短应答停留（≤4 字**且**这句话说完了，比如「怕。」） | ≥1.2s | 一般不用调 |
| 画面上任何文字的字号下限 | 40px | 受众视力弱 → 往上抬，别往下降 |

⚠️ 下调之前先想清楚：**行停留是「读得完」的下限，不是节奏偏好。** 拿不准就留在 2.5s——读不完的字幕，观众划走的速度比你想的快。

⚠️ **单位是「字幕行」不是「音频句」**。对戏必然产生短句，行是由相邻的句子合并出来的。

⚠️ **「字少」和「话说完了」两个条件缺一不可**。模型会在逗号处切句，「写了借条，」这种半截从句也只有 4 个字——只按字数判，它会拿到一张短卡，剩下半句被推去跟别人并卡。

### 第六组：声音

- 旁白想要什么声音？男声女声、快点慢点、播音腔还是像聊天？
- 有几个说话人？（一个人独白，还是有对话？）

音色 ID 要从 MiniMax 控制台的音色列表里**复制**，别凭记忆拼——拼错会直接报 `voice id not exist`，不会悄悄换个人给你念完。

如果他做过声音复刻，复刻槽是挂在他自己 API key 下的资产，换 key 就没了。提醒他把复刻用的源音频留一份档，槽丢了拿那份重刻。

BGM 问不问随他：想要就在配置里留一条基础音量（缺省 `0.10`，判据是「旁白清清楚楚、BGM 若有若无」）。

## 产出

### 1. `handdrawn-studio/editorial.md`

照 `templates/editorial-template.md` **逐字段填**，不改模板结构。填不出来的字段写「待定」，别删掉那一行。

### 2. `handdrawn-studio/studio.config.json`

机器读的那几项。结构：

```json
{
  "accountName": "〔账号名，逐字，会印在角标上〕",
  "platform": "〔目标平台〕",
  "aspectRatio": "9:16",
  "tts": {
    "model": "speech-2.8-hd",
    "voices": { "〔说话人〕": "〔MiniMax 音色 ID〕" },
    "speed": 1.0,
    "defaultGapMs": 700
  },
  "captions": {
    "minLineSeconds": 2.5,
    "shortReplySeconds": 1.2,
    "minFontPx": 40
  },
  "bgm": { "volume": 0.10 }
}
```

`tts.speed` 是**全局缺省语速**，对所有说话人一视同仁。MiniMax 的语速本身是 per-request 的旋钮，所以对戏时**可以只把其中一个人放慢**——覆写走环境变量 `MINIMAX_SPEED_<说话人名>`（想改所有人的缺省就用 `MINIMAX_SPEED_DEFAULT`）。⚠️ 别为此往 `script.json` 顶层补一个 `speed`：那一层优先级最高，补上去会把所有按角色的覆写一起压掉。

两条消费说明，免得以为写了就处处生效：

- 合成脚本直接读的是 `accountName` 之外的 `tts.*` 与 `captions.minLineSeconds` / `shortReplySeconds`，从**项目根**这份读；
- `captions.minFontPx` 与 `bgm.volume` 合成脚本**不读**——它们是给出片段的：出 SPEC 换常量时照抄进工程（字幕字号下限、BGM 基础音量），执行体按 SPEC 落实。`accountName` 由建工程第 4 步拷进工程内 `public/studio.config.json`，引擎构建时从那份读（见 `references/production.md` 第一节）。

## 收尾

两个文件都落盘之后：

1. 把 `editorial.md` 整个念给用户听一遍（或者让他自己打开看），请他确认。
2. 告诉他改配置只要改 `editorial.md` 和 `studio.config.json`，不用重跑访谈。
3. **停在这里。** 他说「开始吧」再进 `daily-flow.md`。
